# Evidências

- `imagens-coleta/` — amostra das imagens capturadas (organizadas por
  `tools/organizar_imagens.py`, com nomes no padrão `classe_001.jpg`).
- `esp32cam-funcionando/` — print ou foto do monitor serial mostrando
  `Câmera OK` / `WiFi OK` / `Servidor OK`, e um print da página web de
  captura sendo usada.
- `roboflow/` — print do projeto no Roboflow mostrando o dataset, as
  classes cadastradas e exemplos de anotação (bounding boxes).
